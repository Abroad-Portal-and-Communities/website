Operate and support production networks so users and services stay connected.

## Typical responsibilities

- User access, Wi‑Fi, and office connectivity
- Patch management, backups, and documentation
- Ticket-driven fixes and scheduled maintenance

## Learning path

1. Help desk or IT support experience
2. Vendor equipment (switches, firewalls, wireless controllers)
3. Monitoring tools (SNMP, NetFlow, observability dashboards)
4. Grow toward network engineer or cloud networking
