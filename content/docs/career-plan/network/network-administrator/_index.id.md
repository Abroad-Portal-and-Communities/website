Mengoperasikan dan mendukung jaringan produksi agar pengguna dan layanan tetap terhubung.

## Tanggung jawab umum

- Akses pengguna, Wi‑Fi, dan konektivitas kantor
- Manajemen patch, backup, dan dokumentasi
- Perbaikan berbasis tiket dan pemeliharaan terjadwal

## Jalur belajar

1. Pengalaman help desk atau dukungan IT
2. Peralatan vendor (switch, firewall, wireless controller)
3. Alat monitoring (SNMP, NetFlow, dashboard observabilitas)
4. Berkembang ke insinyur jaringan atau jaringan cloud
