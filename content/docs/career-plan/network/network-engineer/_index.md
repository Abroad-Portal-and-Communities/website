Design and maintain reliable network infrastructure for organizations.

## Typical responsibilities

- Network architecture and capacity planning
- Routing, switching, load balancing, and WAN connectivity
- Automation with scripts or infrastructure-as-code where applicable

## Learning path

1. Networking fundamentals (OSI model, subnets, VLANs)
2. Lab with GNS3, EVE-NG, or cloud VPCs
3. On-call and troubleshooting real incidents
4. Cloud networking (VPC, peering, transit gateways)
