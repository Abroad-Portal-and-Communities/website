Merancang dan memelihara infrastruktur jaringan yang andal untuk organisasi.

## Tanggung jawab umum

- Arsitektur jaringan dan perencanaan kapasitas
- Routing, switching, load balancing, dan konektivitas WAN
- Otomasi dengan skrip atau infrastruktur sebagai kode jika memungkinkan

## Jalur belajar

1. Fundamental jaringan (model OSI, subnet, VLAN)
2. Lab dengan GNS3, EVE-NG, atau VPC cloud
3. On-call dan troubleshooting insiden nyata
4. Jaringan cloud (VPC, peering, transit gateway)
