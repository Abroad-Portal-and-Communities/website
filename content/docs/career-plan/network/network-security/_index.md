Protect networks and data in transit with defense-in-depth practices.

## Typical responsibilities

- Firewall rules, segmentation, and zero-trust patterns
- IDS/IPS, VPN, and secure remote access
- Security reviews for new services and architecture changes

## Learning path

1. Strong networking foundation
2. Security basics (OWASP, CIS controls, threat modeling)
3. Certifications: Security+, CCNA Security, or cloud security specialty
4. Collaboration with SOC and application security teams
