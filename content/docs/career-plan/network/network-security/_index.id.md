Melindungi jaringan dan data dalam perjalanan dengan praktik defense-in-depth.

## Tanggung jawab umum

- Aturan firewall, segmentasi, dan pola zero-trust
- IDS/IPS, VPN, dan akses remote aman
- Tinjauan keamanan untuk layanan dan perubahan arsitektur baru

## Jalur belajar

1. Fondasi jaringan yang kuat
2. Dasar keamanan (OWASP, CIS controls, threat modeling)
3. Sertifikasi: Security+, CCNA Security, atau spesialisasi keamanan cloud
4. Kolaborasi dengan SOC dan tim keamanan aplikasi
