Bridge development and operations with automation, platforms, and reliability.

## Typical responsibilities

- CI/CD pipelines and infrastructure as code
- Kubernetes, containers, and cloud platforms
- SLOs, incident response, and cost optimization

## Learning path

1. Linux, scripting, and networking basics
2. Cloud provider (AWS, GCP, or Azure) core services
3. Terraform or similar IaC; GitOps workflows
4. Observability: metrics, logs, traces
