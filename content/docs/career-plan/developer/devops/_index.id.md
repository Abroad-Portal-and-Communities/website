Menjembatani pengembangan dan operasi dengan otomasi, platform, dan keandalan.

## Tanggung jawab umum

- Pipeline CI/CD dan infrastruktur sebagai kode
- Kubernetes, container, dan platform cloud
- SLO, respons insiden, dan optimasi biaya

## Jalur belajar

1. Dasar Linux, scripting, dan jaringan
2. Layanan inti penyedia cloud (AWS, GCP, atau Azure)
3. Terraform atau IaC serupa; alur GitOps
4. Observabilitas: metrik, log, trace
