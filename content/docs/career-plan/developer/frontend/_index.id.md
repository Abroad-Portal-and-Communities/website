Membuat antarmuka yang digunakan pengguna — cepat, aksesibel, dan mudah dirawat.

## Tanggung jawab umum

- Pustaka komponen dan design system
- Manajemen state dan integrasi API
- Performa, SEO, dan dukungan lintas browser

## Jalur belajar

1. Dasar HTML, CSS, JavaScript
2. Framework modern (React, Vue, Svelte, dll.)
3. Aksesibilitas (WCAG) dan desain responsif
4. Testing (unit, e2e) dan tooling build
