Create interfaces users interact with — fast, accessible, and maintainable.

## Typical responsibilities

- Component libraries and design systems
- State management and API integration
- Performance, SEO, and cross-browser support

## Learning path

1. HTML, CSS, JavaScript fundamentals
2. A modern framework (React, Vue, Svelte, etc.)
3. Accessibility (WCAG) and responsive design
4. Testing (unit, e2e) and build tooling
