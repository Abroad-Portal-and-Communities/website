Memiliki fitur dari basis data hingga UI — umum di startup dan tim kecil.

## Tanggung jawab umum

- Potongan vertikal: skema, API, dan frontend untuk satu fitur
- Trade-off antara kecepatan dan arsitektur jangka panjang
- Kolaborasi erat dengan desain dan produk

## Jalur belajar

1. Dasar backend + frontend yang solid (jangan lewati fundamental)
2. Satu framework full-stack jika cocok (mis. Next.js, Rails, Django)
3. Kesadaran DevOps: deploy dan pantau yang Anda bangun
4. Dalami satu sisi (backend atau frontend) seiring berkembang
