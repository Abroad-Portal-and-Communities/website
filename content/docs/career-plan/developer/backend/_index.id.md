Membangun sistem sisi server, API, dan lapisan data yang menggerakkan produk.

## Tanggung jawab umum

- API REST atau GraphQL dan batas layanan
- Basis data, caching, dan antrean pesan
- Performa, keandalan, dan observabilitas

## Jalur belajar

1. Satu bahasa backend (Go, Python, Java, Node.js, dll.)
2. SQL dan pemodelan data
3. Dasar auth, testing, dan deployment
4. Konsep sistem terdistribusi saat skala bertambah
