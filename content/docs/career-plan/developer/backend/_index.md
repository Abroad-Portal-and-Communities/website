Build server-side systems, APIs, and data layers that power products.

## Typical responsibilities

- REST or GraphQL APIs and service boundaries
- Databases, caching, and message queues
- Performance, reliability, and observability

## Learning path

1. One backend language (Go, Python, Java, Node.js, etc.)
2. SQL and data modeling
3. Auth, testing, and deployment basics
4. Distributed systems concepts as you scale
