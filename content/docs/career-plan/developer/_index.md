Software engineering career paths and specializations.

## Roles

| Role | Focus |
| --- | --- |
| [Backend Developer](/docs/career-plan/developer/backend/) | APIs, databases, services, and server-side logic |
| [Frontend Developer](/docs/career-plan/developer/frontend/) | UI, accessibility, and client-side applications |
| [Full-Stack Developer](/docs/career-plan/developer/full-stack/) | End-to-end features across frontend and backend |
| [Mobile Developer](/docs/career-plan/developer/mobile/) | iOS, Android, and cross-platform apps |
| [DevOps Engineer](/docs/career-plan/developer/devops/) | CI/CD, platforms, and developer productivity |

## Common foundations

- Data structures, algorithms, and clean code
- Git, code review, and agile delivery
- One primary language plus willingness to learn others
