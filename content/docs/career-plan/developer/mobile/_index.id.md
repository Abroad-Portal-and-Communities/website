Mengirim aplikasi native atau lintas platform untuk iOS dan Android.

## Tanggung jawab umum

- Arsitektur aplikasi, perilaku offline, dan push notification
- Rilis app store dan kompatibilitas perangkat
- Integrasi dengan API backend dan analitik

## Jalur belajar

1. Swift/Kotlin untuk native, atau Flutter/React Native untuk lintas platform
2. Pola UX mobile dan panduan platform
3. Profiling performa dan pelaporan crash
4. Keamanan: penyimpanan aman, certificate pinning jika diperlukan
