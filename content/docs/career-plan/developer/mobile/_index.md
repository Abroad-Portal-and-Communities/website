Ship native or cross-platform apps for iOS and Android.

## Typical responsibilities

- App architecture, offline behavior, and push notifications
- App store releases and device compatibility
- Integration with backend APIs and analytics

## Learning path

1. Swift/Kotlin for native, or Flutter/React Native for cross-platform
2. Mobile UX patterns and platform guidelines
3. Performance profiling and crash reporting
4. Security: secure storage, certificate pinning where needed
