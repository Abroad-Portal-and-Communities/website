Productionize machine learning: training pipelines, serving, and monitoring.

## Typical responsibilities

- Feature pipelines and model training workflows
- Model serving, A/B tests, and drift detection
- GPU/CPU cost management and reproducibility

## Learning path

1. Data engineering fundamentals + Python
2. ML basics (supervised learning, evaluation metrics)
3. MLOps: experiment tracking, model registry, CI for models
4. Collaboration with data scientists on handoff to production
