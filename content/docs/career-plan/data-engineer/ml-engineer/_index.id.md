Memproduksikan machine learning: pipeline pelatihan, serving, dan monitoring.

## Tanggung jawab umum

- Pipeline fitur dan alur pelatihan model
- Serving model, uji A/B, dan deteksi drift
- Manajemen biaya GPU/CPU dan reproduksibilitas

## Jalur belajar

1. Fundamental data engineering + Python
2. Dasar ML (supervised learning, metrik evaluasi)
3. MLOps: pelacakan eksperimen, model registry, CI untuk model
4. Kolaborasi dengan data scientist untuk handoff ke produksi
