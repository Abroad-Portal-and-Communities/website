Move and transform data reliably from sources to warehouses and lakes.

## Typical responsibilities

- Batch and streaming pipelines (Spark, Flink, Kafka, Airflow, Dagster)
- Data quality checks and lineage
- Cost and performance tuning for large datasets

## Learning path

1. SQL + Python; understand schema design
2. One orchestration tool and one warehouse
3. Idempotency, backfills, and failure handling
4. Data governance and privacy basics
