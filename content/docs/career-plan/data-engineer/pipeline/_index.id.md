Memindahkan dan mentransformasi data secara andal dari sumber ke warehouse dan lake.

## Tanggung jawab umum

- Pipeline batch dan streaming (Spark, Flink, Kafka, Airflow, Dagster)
- Pemeriksaan kualitas data dan lineage
- Penyetelan biaya dan performa untuk dataset besar

## Jalur belajar

1. SQL + Python; pahami desain skema
2. Satu alat orkestrasi dan satu warehouse
3. Idempotensi, backfill, dan penanganan kegagalan
4. Dasar tata kelola data dan privasi
