Mengubah data mentah menjadi metrik dan model terpercaya untuk analis dan pemangku kepentingan.

## Tanggung jawab umum

- Proyek dbt, model dimensional, dan dokumentasi
- Lapisan semantik dan BI self-serve
- Bermitra dengan analis tentang definisi dan pengujian

## Jalur belajar

1. SQL lanjutan dan konsep warehouse
2. dbt atau framework transformasi serupa
3. Alat BI (Looker, Metabase, Tableau, dll.)
4. Komunikasi dengan tim produk dan bisnis
