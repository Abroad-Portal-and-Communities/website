Career paths for building data platforms, pipelines, and analytics at scale.

## Roles

| Role | Focus |
| --- | --- |
| [Data Pipeline Engineer](/docs/career-plan/data-engineer/pipeline/) | Ingestion, ETL/ELT, orchestration, and data quality |
| [Analytics Engineer](/docs/career-plan/data-engineer/analytics/) | dbt, warehouses, and metrics for business teams |
| [ML Engineer](/docs/career-plan/data-engineer/ml-engineer/) | Feature stores, model deployment, and MLOps |

## Common foundations

- SQL and data modeling
- Python or Scala for data jobs
- Cloud data services (BigQuery, Snowflake, Redshift, etc.)
