Bekerja di Jerman sebagai warga negara asing. Untuk dasar kontrak dan dokumen tingkat UE, lihat [Legal & dokumen (Eropa)](/docs/working-abroad/eu/legal-and-documents/).

{{< callout type="warning" >}}
Aturan berubah. Gunakan sumber resmi (mis. [Make it in Germany](https://www.make-it-in-germany.com/en/)) dan konsultasikan penasihat imigrasi atau hukum untuk kasus Anda.
{{< /callout >}}

## Jalur umum (ringkasan)

| Jalur | Catatan |
| --- | --- |
| EU Blue Card | Pendidikan tinggi + pekerjaan kualifikasi + ambang gaji (diperbarui tahunan) |
| Pekerja terampil (*Fachkraft*) | Kualifikasi vokasi atau akademik diakui di Jerman |
| Izin ICT | Transfer intra-perusahaan dalam grup |
| Pencari kerja | Tinggal terbatas untuk mencari pekerjaan kualifikasi |
| Kebebasan bergerak UE | Warga UE/EEA/Swiss — pendaftaran, bukan visa |

## Langkah lokal (setelah masuk)

Urutan umum; kota Anda (`Ausländerbehörde`, `Bürgeramt`) bisa berbeda:

1. **Pendaftaran alamat** (*Anmeldung*) di kantor pendaftaran setempat sesuai tenggat
2. **Izin tinggal** — Ambil atau perpanjang di kantor orang asing jika masuk dengan visa di paspor
3. **ID pajak** (*Steueridentifikationsnummer*) — Diterbitkan kantor pajak; diperlukan untuk penggajian
4. **Asuransi sosial** — Biasanya diatur pemberi kerja (kesehatan, pensiun, pengangguran)
5. **Rekening bank** — Banyak pemberi kerja membayar gaji ke IBAN Jerman

## Dokumen yang disiapkan

Gunakan [daftar periksa dokumen](/docs/working-abroad/eu/legal-and-documents/#daftar-periksa-dokumen-template) bersama dan tambahkan persyaratan Jerman dari pemberi kerja atau kedutaan (mis. pengakuan kualifikasi via [Recognition in Germany](https://www.anerkennung-in-deutschland.de/html/en/index.php)).
