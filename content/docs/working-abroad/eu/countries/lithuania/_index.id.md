Bekerja di Lituania sebagai warga negara asing. Untuk dasar kontrak dan dokumen tingkat UE, lihat [Legal & dokumen (Eropa)](/docs/working-abroad/eu/legal-and-documents/).

{{< callout type="warning" >}}
Aturan berubah. Pastikan dengan [Departemen Migrasi](https://www.migracija.lt/en/) dan penasihat resmi untuk situasi Anda.
{{< /callout >}}

## Jalur umum (ringkasan)

| Jalur | Catatan |
| --- | --- |
| EU Blue Card | Pekerjaan kualifikasi dengan syarat gaji dan kualifikasi |
| Izin kerja nasional + tinggal | Pemberi kerja sering menginisiasi; kategori sesuai peran dan keahlian |
| Izin ICT | Transfer intra-korporat |
| Kebebasan bergerak UE | Warga UE/EEA/Swiss — deklarasi tempat tinggal |

## Langkah lokal (setelah masuk)

Urutan umum; Vilnius, Kaunas, dan kotamadya lain bisa sedikit berbeda:

1. **Izin tinggal** — Ajukan atau ambil kartu di Departemen Migrasi (*Migracijos departamentas*) jika diperlukan untuk kewarganegaraan Anda
2. **Deklarasi alamat** — Daftar tempat tinggal ke kotamadya
3. **Kode pribadi** (*asmens kodas*) — Diperlukan untuk pekerjaan, kontrak, dan banyak layanan
4. **Asuransi sosial** — Pendaftaran via pemberi kerja (*SODRA*)
5. **Rekening bank** — IBAN lokal untuk gaji

## Dokumen yang disiapkan

Gunakan [daftar periksa dokumen](/docs/working-abroad/eu/legal-and-documents/#daftar-periksa-dokumen-template) plus persyaratan kedutaan atau pemberi kerja (terjemahan ke Lituania atau Inggris sesuai ketentuan).
